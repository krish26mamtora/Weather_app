<h1>Weather Forecast Website</h1>
<h2>Key Features</h2>
<ul>
    <li>Displays weather data such as temperature, humidity, and wind information.</li>
    <li>Real-time weather updates fetched via the <code>RapidAPI</code> Weather API.</li>
    <li>Interactive UI with a responsive design by Bootstrap.</li>
</ul>

<h2>Technologies Used</h2>
<ul>
    <li><b>HTML5</b> - Structure and content.</li>
    <li><b>CSS (Bootstrap)</b> - Styling and layout.</li>
    <li><b>JavaScript</b> - API integration and dynamic updates.</li>
    <li><b>RapidAPI</b> - Weather data provider.</li>
</ul>
